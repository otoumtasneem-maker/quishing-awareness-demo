What is Quishing?

Quishing (QR Code Phishing) is a phishing technique that uses a QR code to direct someone to a deceptive or harmful destination. A QR code itself does not grant camera access: the website it opens must separately request permission, and the user must approve it.

  • Check the destination URL before opening it.
  • Be cautious if an unexpected page asks for permissions or personal information.
  • Do not enter passwords, payment details, or one-time codes on untrusted pages.

ماذا تعلمنا؟

مسح رمز QR لا يمنح الموقع صلاحية الكاميرا تلقائياً. الموقع الذي يفتحه الرمز قد يطلب هذه الصلاحية بشكل منفصل، ويجب على المستخدم الموافقة عليها.
